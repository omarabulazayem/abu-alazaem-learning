# Child Worlds UI

This visual layer supports the simplified child-facing experience, especially ages 4–8.

Principles:
- three primary choices first: memorize, play, review
- secondary rewards/mission/room controls stay smaller
- scene-based cards instead of repeated dashboard cards
- no decorative emoji dependency
- large touch targets and RTL/mobile support
- media credits stay outside child mode
- teacher navigation remains separate from child learning navigation
